# banking-recommendation-system
End-to-end ML system for banking product recommendations using customer behavior, risk scoring, FastAPI backend, PostgreSQL, and Streamlit dashboard.

# Banking Recommendation System

## Tech Stack
- Python
- PostgreSQL
- FastAPI
- Streamlit
- XGBoost

## Features
- Customer profiling
- Risk scoring
- ML recommendations
- Real-time API
- Interactive dashboard

## Run Project

### Backend
uvicorn backend.main:app --reload

### Frontend
streamlit run frontend/streamlit_app.py
